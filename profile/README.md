## Build with the Centuro API

Bring your Centuro cases into your HR system, data warehouse or internal tools.

### ⚡ [centuro-api-quickstart](https://github.com/Centuro-Global/centuro-api-quickstart)

Clone it, add your API key, and make your first call in under a minute. It contains:

- a typed TypeScript client with no dependencies, which handles tokens, paging and errors for you
- example scripts you can run straight away
- a Postman collection with tests for every endpoint

```bash
git clone https://github.com/Centuro-Global/centuro-api-quickstart.git
cd centuro-api-quickstart && npm install && cp .env.example .env
# add your client ID and secret to .env, then:
npm run me
```

To get an API key, speak to your Centuro contact or [get in touch](https://www.centuroglobal.com/contact-us/).
